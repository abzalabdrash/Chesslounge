# Chess Lounge

Сайт: **https://chesslounge-iota.vercel.app**

3D-комната, в которой можно подойти к столу, сесть напротив AI-соперника и сыграть в шахматы. У каждого противника свой характер, свой ELO и свой голос — комментирует каждый ход в живую.

## Что внутри

- Трёхмерный лаунж в браузере — управление WASD/стрелки, бег на Shift, садишься за стол клавишей `E`, выходишь `Esc`.
- Три персонажа со своими личностями:
  - **The Hustler** (ELO 1900) — наглый парковый шахматист.
  - **Maestro** (ELO 2400) — старая школа, цитирует Капабланку.
  - **Tilt** (ELO 1700) — стримерша, держится пока не зевнёт ферзя.
- Настоящий движок Stockfish (через `chess.js` + WebAssembly), сила игры подстраивается под ELO выбранного соперника.
- Анализ каждого хода в стиле chess.com: brilliant / great / best / inaccuracy / mistake / blunder, с эвал-баром и точностью по сторонам.
- Живой комментарий через LLM (Featherless / Mistral Nemo) — персонаж реагирует на бландеры, шахи, маты и берёт ферзей в характере. Если ключа нет, идут заранее написанные реплики.
- Звуки ходов, шаха, мата и фоновая атмосфера лаунжа.

## Технологии

- **React 19** + **TypeScript** + **Vite**
- **react-three-fiber** + **@react-three/drei** + **Three.js** для 3D-сцены
- **chess.js** + Stockfish (WASM) для движка и анализа
- **Tailwind CSS** + **framer-motion** для UI и анимаций
- **Zustand** для состояния
- Модели персонажей — Meshy AI, мебель — Kenney Furniture Kit (CC0)

## Управление

| Клавиша | Действие |
| --- | --- |
| `WASD` / стрелки | ходить |
| `Shift` | бежать |
| `E` | сесть за ближайший стол |
| `Esc` | встать |
| `M` | выкл / вкл звук |
